# 🍦 ScoopDream 

> **Artisan Ice Cream, Crafted With Love.** 💖

ScoopDream is a premium, retro-luxe ice cream brand landing page built with **Next.js 16**. It features a stunning, image-rich design, smooth Framer Motion animations, and a focus on premium aesthetics. ✨

## 🌟 Features

- 🎨 **Retro-Luxe Editorial Aesthetic:** A premium design that wows at first glance.
- 🌓 **Dark/Light Mode Switching:** Beautifully crafted themes for both preferences.
- 🎞️ **Cinematic Hero Sequence:** A stunning 80-frame image sequence powered by Framer Motion.
- 📱 **Fully Responsive:** Looks perfect on any device.
- 💫 **Micro-animations:** Smooth scrolling, hover effects, and entrance animations.
- 📍 **Store Locator:** Dynamic store hours and mapping integration. 

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org) (App Router)
- **Styling:** Vanilla CSS & CSS Modules 
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Fonts:** Custom typography with standard Next.js font optimization

## 🚀 Getting Started

